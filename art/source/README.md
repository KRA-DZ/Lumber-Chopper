# Исходный лист лагеря

`camp-sheet.png` — оригинальный сгенерированный лист 1536×1024 на белом фоне. Исходное изображение сохраняется отдельно от игровых PNG и не включается в `dist/`.

Раскладка 3×2 слева направо: палатка, деревянный дом торговца, торговец в капюшоне; ель, берёза, холодное кострище. Промпт задавал оригинальный подробный 16-bit pixel-art, вид 3/4 сверху, чисто-белый фон без подписей, земли и размытых падающих теней; оттенки коры берёзы — слоновая кость/серый. Ориентир — уютные фермерские RPG, без заимствования готовых игровых изображений.

Верхушка ели немного пересекает условную границу строки. Скрипт группирует целые контуры, поэтому она сохраняется полностью.

Воспроизведение поставленного набора:

```sh
python scripts/prepare_assets.py art/source/camp-sheet.png --background all --defringe 1
```

Параметры и SHA-256 исходника записаны в `src/assets/manifest.json`. Подробности: [ASSET-PIPELINE.md](../../docs/ASSET-PIPELINE.md).
