После [людей](CHARACTERS.md) подключены четыре вида деревьев, три состояния восстановления каждого и древний дуб — всего 17 изображений. ## Как читать коллаж

Четыре горизонтальные строки — четыре варианта силуэтов в одном стиле. В каждой строке слева направо: обычный дуб, ель, берёза, сухое дерево, огромный древний дуб для работников. Маленький герой помогает сравнить размеры; внизу показаны пень, росток и молодое дерево. Номера относятся ко всей строке, а не к отдельному виду дерева.

| № | Направление | Отличия |
| --- | --- | --- |
| 1 | Уютный классический лес | Округлые густые кроны, пушистая ель, светлая берёза, тёплая кора. |
| 2 | Высокий стройный лес | Более вытянутые стволы, ярусные кроны, узкая высокая ель, сдержанная хвойная зелень. |
| 3 | Сказочный лес | Изогнутые стволы, широкие мягкие силуэты, яркая зелень, раскидистый древний дуб. |
| 4 | Старый мшистый лес | Потемневшая кора, мох у корней, неровные ветви, естественное дупло и небольшие древесные грибы. |

Можно выбрать одну строку для всего набора или смешать виды: например, обычные деревья из одной строки, древний дуб из другой. Выбранные ранее биомы, враги и люди сохраняют согласованные образы. Мшистое дерево не становится новым существом или отдельным биомом.

## Игровые изображения и прозрачность

Три новых исходника в `art/source/` — настоящие RGBA PNG с прозрачным фоном: `trees-mature-sheet.png`, `trees-growth-sheet.png`, `tree-ancient-sheet.png`. Белая кора берёзы остаётся непрозрачной. Белый фон не вычитается из новых изображений по цвету. Общий PNG-конвейер также автоматически доверяет готовому alpha-каналу и пропускает старую очистку белой подложки. Для последующих изолированных объектов также запрашивается прозрачный PNG; земля и вода остаются непрозрачными материалами.

`python scripts/prepare_trees.py` выделяет компоненты по исходному alpha, убирает слабый шум прозрачности порогом 128, формирует чёткие пиксельные края, обнуляет скрытый RGB и упаковывает 17 кадров в `src/assets/trees/trees.png` размером 1024×512. В манифесте — SHA-256 оригиналов, области, точки основания и выбранный вариант. Обычные деревья имеют высоту 148–178 исходных пикселей; молодые — 84, ростки — 22. Крупный вариант на 14% больше обычного; варианты обычного размера переиспользуют одно изображение. У древнего дуба отдельный широкий силуэт в пределах 360×264 пикселей. Все изображения на карте увеличены вдвое.

`phaser/tree-assets.js` загружает один PNG, сохраняет декодированное изображение для перезапуска и освобождает временную GPU-текстуру. Изображения подставляются до подготовки ветра и масок нажатия. Рендерер использует отдельные `growth.<вид>.stump/sprout/young`, а не уменьшенное зрелое дерево. Цикл остаётся прежним: пень в день рубки, росток на следующий день, молодое дерево на второй, зрелое на третий. Урожай 2/3 бревна, размеры коллизий, проходимость пней и производство работников не изменены.

Общий атлас остаётся 2048×2048; декодированный исходный лист деревьев занимает около 2 MiB RGBA для перезапуска. Дополнительных спрайтов на каждое дерево и обработки изображений в игровом цикле нет. `?art=procedural` сохраняет прежние деревья для сравнения; исходная Canvas-версия остаётся `index.html`. Постройки и их состояния согласуются следующим отдельным набором.

## Исправление старых краёв

Старые непрозрачные исходники сохранены без изменения. Их подготовка дополнена восстановлением цвета на узкой границе силуэта: светлый пиксель сравнивается со смесью белого и соседнего внутреннего цвета, затем восстанавливаются цвет и покрытие alpha. Светлая внутренняя кора и одежда не удаляются. Новые деревья этот совместимый со старыми исходниками шаг не используют.

Заново подготовлены старый лагерь, люди, враги, Смотритель и декор. При сборке общего атласа устранено повторное наложение одного bitmap для нескольких имён кадров: прозрачность больше не накапливается на общих кадрах анимаций. `prepare_people.py` теперь сохраняет восстановленную полупрозрачность вместо замены всей маски на непрозрачную. Это исправление не означает, что прежние белые исходники стали настоящими прозрачными оригиналами.

## Проверки

```sh
python scripts/prepare_trees.py
python -m unittest discover -s tests -p '*assets*_test.py'
npm test
npm run build
python tests/trees_smoke.py
python tests/imported_assets_smoke.py
python tests/watcher_smoke.py
```

Контракты PNG проверяют происхождение, все состояния, прозрачность, отсутствие скрытого белого RGB, сохранность светлой берёзы и границы атласа. Браузерный сценарий проверяет настоящую рубку каждого вида, три рассвета, платное открытие рощи, ночь, перезапуск и мобильный WebGL/Canvas. Часть сценария ускоряется установкой времени перед рассветом и выдачей ресурсов для проверки пограничной покупки.

## Источник

`tree-style-collage.png` создан генератором изображений с `art/source/camp-sheet.png` и `docs/character-style-collage.png` как визуальными референсами. Заданы оригинальный подробный 16-bit pixel-art, вид 3/4 сверху, общая палитра и дневной свет сверху слева. Сгенерированный коллаж сохраняется без редактирования. Это концептуальное сравнение: финальные игровые размеры и набор кадров проверяются отдельно после выбора.

Финальные листы сгенерированы с утверждённым коллажем и лагерем как референсами. Исходники хранятся без изменения; нарезка и подготовка выполняются отдельно.
