# Цвета героев перед началом смены

Согласованы все четыре варианта [коллажа](hero-color-collage.png): исходные, лесные, бордовые и туманные. Это палитры существующих путешественника и лесорубки, а не новые силуэты или одежда. Применить набор можно одной кнопкой; волосы, куртку и брюки также можно настраивать отдельно — 64 сочетания на героя.

## Выбор и предпросмотр

В стартовом диалоге появились реальные игровые кадры с поворотом в четыре стороны и режимами покоя, ходьбы, переноски и рубки. Для левого направления используется то же отражение бокового кадра, что в игре. При `prefers-reduced-motion` начальный предпросмотр неподвижен. До «Начать смену» мир и игровой таймер не создаются.

Вдвоём у каждого собственные персонаж и три цвета; разрешено выбрать одного и того же героя. По умолчанию второму предлагается другой герой, пока он явно не выбрал своего. Прокачка от внешности не зависит. Все цвета сбрасываются при загрузке страницы; внутренний перезапуск сцены сохраняет выбор текущего сеанса, сбрасывая игровой прогресс. Новых сохранений нет.

## Реализация

- `game/hero-colors.js` — четыре фиксированные палитры, нормализация отдельных материалов, сохранение теней при замене RGB. Недопустимые значения заменяются исходным цветом соответствующей части.
- `state.heroColors` — личные визуальные настройки. В кооперативе не входят в общие ключи мира; цены, HP, скорость, вместимость и урон прежние.
- `scripts/prepare_hero_masks.py` — офлайн-маски 162 готовых кадров. Используются геометрия позы и признаки исходных цветов; слои новых причёсок/одежды не добавлялись. Для вариантов редкости топора используется одна маска базовой позы.
- `src/assets/people/hero-materials.png` — метки материалов в прежней раскладке кадров. Манифест `hero-materials.json` содержит SHA-256 исходного `people.png` и покрытие кадров. Исходные изображения людей и NPC не переписывались. `prepare_people.py` обновляет маски после подготовки атласа.
- `phaser/hero-color-art.js` — общая отрисовка для предпросмотра и игры; альфа, размеры и опоры кадров сохраняются.
- `phaser/people-assets.js` — перекраска только выбранных вариантов при построении игрового атласа, с кешем по кадру и сочетанию цветов. NPC используют прежние кадры. Временная GPU-текстура масок освобождается; метки хранятся в массиве 1 МиБ.
- `phaser/hero-customizer.js` — личные панели и ограниченный кеш предпросмотра. Кадры меняются до восьми раз в секунду; при начале игры обработчики и анимационный запрос удаляются. В игровом `update()` перекраски нет.

Подготавливаются выбранные образы, а не атлас всех 128 комбинаций. Лимит общего игрового атласа 2048 по высоте сохранён; сборка работает без внешних сервисов.

## Целевые проверки

```sh
python scripts/prepare_hero_masks.py
python tests/hero_materials_test.py
node --test tests/hero-colors.test.mjs tests/appearances.test.mjs tests/local-coop.test.mjs tests/runtime-entry.test.mjs
npm run build
python tests/hero_colors_smoke.py
```

18 Node-тестов: нормализация, независимость от характеристик, личные цвета, одинаковый герой вдвоём, исходные пиксели и прозрачность. Проверка масок охватывает источник, все 162 кадра, прозрачность, отсутствие меток на NPC и сохранение светлых пикселей кожи/рубашки.

Браузер: WebGL вдвоём и мобильный Canvas из сборки; выбор отдельных цветов, живой предпросмотр/поворот, два варианта одного героя, сравнение игровых кадров с нужным образом для ходьбы/переноски/рубки и разных топоров, клавиатура, перезапуск сцены, сброс при загрузке. Предел атласа проверен. Полная игра повторно не тестировалась.
