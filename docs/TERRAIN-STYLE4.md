# Земля и дорожки — выбранный вариант №4

Выбран нижний правый вариант [коллажа](terrain-style-collage.png): холодная приглушённая зелень и серо-коричневые тропинки. По нему сгенерирован отдельный лист `art/source/terrain-style4-sheet.png`. Люди, деревья и палатка из коллажа служили ориентирами; их изображения в игре не заменялись.

## Материалы и подготовка

Заменены восемь прежних PNG 64×64 в `src/assets/biomes/`: лес, поле, болото, берег, паутинный лес, руины, земля дорожек и вода. Биомы сохраняют различия: серо-шалфейное поле, влажное оливковое болото, тёмный паутинный лес, каменистые руины. Девятая ячейка листа — запасная трава, в игру не загружается.

Это сплошные поверхности, поэтому PNG полностью непрозрачны: прозрачность открывала бы дыры в земле. Белого фона нет. Прозрачные изображения отдельных предметов сохранены.

`python scripts/prepare_ground.py` подготавливает только землю: сетка 3×3, уменьшение nearest-neighbor, согласование противоположных краёв в восьмипиксельной полосе. Размеры, стиль и SHA-256 исходника записаны в манифест. Общий `scripts/prepare_biomes.py` вызывает ту же функцию и не возвращает старые материалы.

## Переходы и нагрузка

Границы биомов используют прежнее смешивание по мировым координатам. Внутри края дорожек добавлена нерегулярная полоса перехода к той же траве шириной до 12 мировых единиц. Увеличенный служебный отступ маски сохраняет переход на границе кешируемого участка. Размытие и сглаживание картинки не включались.

Обработка выполняется при создании участка. Размер тайлов, число материалов и лимиты CPU/GPU-кеша прежние. Новых спрайтов и эффектов на каждый кадр нет. Навигация, вода/броды, стоимость открытия регионов, свет и полы исследуемых построек сохранены.

## Целевые проверки

```sh
python tests/biome_assets_test.py
node --test tests/ground-fringe.test.mjs tests/biomes.test.mjs tests/biome-atmosphere.test.mjs
npm run build
python tests/ground_style4_smoke.py
```

Прошли четыре проверки PNG/манифестов, 15 Node-тестов и сборка. Браузер: загрузка материалов, край дорожки на стыке участков и в отрицательных координатах, дневной/ночной вид, разделение камер, ограниченность и повторное использование кеша. ПК — WebGL, телефон — Canvas из сборки. FPS на физических устройствах не измерялся.
