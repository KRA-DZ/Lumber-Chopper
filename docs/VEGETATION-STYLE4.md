# Растительность — выбранный вариант №4

Использован нижний правый вариант [коллажа](vegetation-style-collage.png): холодная ярусная ель, серебристая берёза, дуб с крупными массами листвы и приглушённые ягодные кусты. Цвета согласованы с [землёй №4](TERRAIN-STYLE4.md). Герой и палатка из коллажа были ориентирами; их PNG не заменялись.

## Покрытие

- Четыре вида взрослых деревьев: дуб, ель, берёза, сухое дерево. Для каждого нарисованы отдельные пень, росток и молодое дерево.
- Отдельный древний дуб для работников; механика бесконечной древесины прежняя.
- Три формы ягодных кустов, для каждой пустой, спелый и цветущий кадры. Ягоды выделены красным на холодной листве.
- Прежние грибы, камыш, папоротник, маленький кустарник, изображение ягоды и её иконка сохранены побитно.

Изменены только изображения, метаданные и офлайн-подготовка. Размеры коллизий, высоты деревьев, точки размещения, число ресурсов, скорость роста и правила общего урожая не менялись. runtime-классы деревьев и кустов используют прежние имена кадров, ветер, приглушение крон и сортировку по глубине.

## Подготовка

`art/source/trees-style4-sheet.png` — сгенерированный лист 16 состояний, `tree-ancient-style4-sheet.png` — древний дуб. `scripts/prepare_trees.py` отделяет силуэты по компонентам alpha и фактическим границам полос (генератор сделал их неодинаковыми), сохраняет белую кору и нормализует к прежним высотам. Атлас 17 кадров остаётся 1024×512, предел 1024².

`art/source/bushes-style4-sheet.png` — сетка 3×3. `scripts/prepare_bushes.py` подменяет только девять кадров в прежнем атласе растений 256×256; вызывается из `scripts/prepare_plants.py`. Масштаб общий для трёх состояний каждого куста, основание во всех кадрах `[32,60]`.

Порог alpha удаляет полупрозрачный фон/ореол, не вырезая светлую кору и цветы по белому цвету. Рабочие PNG имеют только прозрачные и непрозрачные пиксели. Источники и SHA-256 записаны в манифесты. Новых текстур на каждый кадр и дополнительных игровых объектов нет.

```sh
python scripts/prepare_trees.py
python scripts/prepare_plants.py
python tests/tree_assets_test.py
python tests/plants_assets_test.py
node --test tests/berries.test.mjs tests/world-readability.test.mjs
npm run build
python tests/vegetation_style4_smoke.py
```

Проверены 17 кадров деревьев, 16 кадров растений, границы атласов, прозрачность, опоры, происхождение и различимость ягод. Прошли 7 целевых Node-тестов и сборка. Браузерный сценарий: WebGL вдвоём и мобильный Canvas из сборки; рубка всех четырёх видов, переходы через пень/росток/молодое/взрослое дерево, древний дуб, сбор через E, общий урожай и восстановление ягод. Полная игра повторно не проверялась.
