# Перенос на Phaser 3

Первая рабочая сцена доступна на `/phaser.html`. `/index.html` пока остаётся полной версией для сравнения. Ссылки между версиями находятся над игровым полем. Старые сохранения отключены в обеих версиях.

Это отдельный этап миграции: мир отрисовывается настоящими `Phaser.GameObjects.Image` и `Sprite`, а не одной текстурой со старым Canvas-циклом. `Phaser.Camera`, `Input`, `AnimationManager`, `TweenManager` и `ParticleEmitter` управляют камерой, вводом, ходьбой, взмахами, падением деревьев, перелётами и щепками.

Примеры: [лагерь в Phaser](phaser-camp.png), [мобильный экран](phaser-camp-mobile.png), [лавка](phaser-shop.png).

## Что перенесено

- WASD, стрелки, мышь и тач, выбор дерева по непрозрачным пикселям. При перекрытии крон ближайшее доступное для рубки дерево имеет приоритет.
- Фиксированное направление камеры, прежний масштаб персонажа и отдельный мобильный размер обзора; поворота и ручного отдаления нет.
- Тот же мир 3200×3200, распределение деревьев/декора, вода, мост, девять полян и огромное дерево для будущих работников.
- Автоматическая и активная рубка, 2–3 бревна, остатки на земле, стартовая переноска двух брёвен, точная цена каждого бревна.
- Обычные покупатели до 5 брёвен, тележки до 15, очередь и закрытие вечером; реальные монеты и все пять товаров лавки.
- Костёр, палатка, связный забор и хижина, частичное строительство, новые радиусы и сообщение об открытии территории.
- Сутки 600 секунд, три стадии отрастания и безопасное восстановление коллизий зрелого дерева.
- Пауза при открытой лавке, потере фокуса и скрытии вкладки. Причины паузы независимы: закрытие одной не снимает другую.
- Ограниченные ресурсы: до 28 чанков земли в исходном кеше, только видимые чанки в текстурах Phaser, до 16 перелётов, 4 падающих деревьев, 64 щепок и 32 всплывающих надписей.

## Следующий этап

В полной Canvas-версии остаются расширенные ночные маски/глаза и находки, погода, животные, звуковое окружение, дополнительные жесты жителей и тонкие анимации растительности. Их нужно переносить и проверять отдельно. Эта первая сцена не заменяет их упрощёнными обещаниями в интерфейсе.

Изображения пока прежние. Движок не повышает качество нарисованных текстур автоматически. Следующая работа над графикой — согласованный оригинальный набор тайлов, персонажей, деревьев и зданий с покадровыми анимациями. В дальнейшем атлас, созданный в `phaser/atlas.js`, можно заменить готовым PNG/JSON-атласом без переписывания экономики и навигации.

## Общий код и границы

`game/config.js`, `game/world-model.js` и `game/navigation.js` используются обеими версиями. Правила снаряжения, инвентаря и роста по-прежнему находятся в общих `economy.js` и `forestry.js`. Координаты, цены, круглые стволы, скруглённые основания, скольжение и A\* не менялись при переносе.

`game/simulation.js` — независимая от браузера симуляция пробной сцены. Она отправляет события рубки/перелёта/продажи; завершение анимации не меняет количество ресурсов. `phaser/world-scene.js` связывает модель со спрайтами и камерой, `phaser/hud-scene.js` отвечает за экранный интерфейс и мини-карту. `phaser/terrain-layer.js` выгружает покинутые чанки вместе с их текстурами. Отрисовка частичного здания выпекается в одну небольшую текстуру только при изменении вложенного количества брёвен.

## Запуск и воспроизводимая сборка

Для игры из клона достаточно статического сервера:

```sh
python -m http.server 8000
```

Откройте `http://localhost:8000/phaser.html`. Phaser 3.90.0 включён локально в `vendor/phaser/`, MIT-лицензия сохранена. Runtime-запросов к CDN, npm или сторонним изображениям нет.

Для восстановления библиотеки из зафиксированного npm-пакета:

```sh
npm ci
npm run vendor
```

Версия и целостность пакета зафиксированы в `package-lock.json`; скрипт также проверяет SHA-256 файла движка. `node_modules/` не включается в публикуемую игру.

```sh
npm run build
python -m http.server 8000 --directory dist
```

Сборка начинает игру с `dist/index.html` и включает только локальные зависимости пробной версии. Её исходный объём около 1.35 MB; сам Phaser — 1,196,122 байта, или 318,115 байт при gzip. Последняя цифра описывает сжатие, а не гарантированное время загрузки на телефоне.

## Яндекс Игры

Формат статической HTML5-сборки подходит для дальнейшей интеграции. SDK Яндекс Игр, сигнал готовности, события игрового процесса и рекламные вызовы на этом этапе не подключались. Перед публикацией нужны отдельная интеграция SDK, проверка пауз/звука при рекламе, материалы страницы игры и проверка актуальных требований платформы. Сборка не означает прохождение модерации.

## Проверки

```sh
npm test
npm run build
python tests/phaser_smoke.py
python tests/browser_smoke.py
python tests/animations_smoke.py
python tests/world_smoke.py
python tests/progression_smoke.py
```

Тест Phaser использует настоящий WebGL в headless Chromium и отдельно настоящий Canvas fallback с отключённым WebGL. Проверяет клавиатуру, тач, следование камеры, пиксельное нажатие, заработанную покупку, паузу, поворот экрана, все стадии лагеря, пределы текстур и перезапуск сцены. Это функциональные проверки; показатели на физических телефонах ещё нужно измерять.
