# Экран, обзор и панель действий

Мир занимает всё окно браузера с момента загрузки. Выбор двух прежних героев остаётся модальным стартовым экраном: до нажатия «Начать смену» симуляция не создаётся. Настоящий Fullscreen API, скрывающий панели браузера, не включается автоматически.

## Масштаб

`phaser/viewport.js` задаёт логическое разрешение по пропорциям окна. В горизонтальном окне видимая высота обычно равна 720 игровым единицам: широкий экран показывает больше леса по бокам, сохраняя размер объектов. Портрет ориентирован на прежнюю ширину 512 единиц, с ограничением высоты 1024. Для очень широких окон ширина ограничена 1600, пропорции сохраняются. Например, окно 1280×720 показывает 1280×720 единиц мира вместо прежних 960×688.

Phaser FIT подгоняет это разрешение под весь контейнер. При изменении окна обновляются размер родителя и `setGameSize()`, включая соотношение сторон. Нет умножения на devicePixelRatio: переход с 1080p на 4K той же формы не увеличивает внутренний холст. Максимум — 1600 по ширине, 1024 по высоте, без растяжения пропорций спрайтов. Это ограничивает стоимость отрисовки, но не является измерением FPS на реальных устройствах.

Кооператив сохраняет существующие две камеры и правила разделения; размеры и порог разделения используют актуальные логические размеры. Одиночная камера имеет тот же вертикальный отступ 80, что и совместная. Масштабы PNG и размеры мира не менялись.

## Интерфейс

`phaser/viewport.css` размещает ресурсы и кнопки компактной панелью поверх нижнего края мира. На узком экране видны «К лагерю», «Лавка», «Пауза» и «Ещё»; последняя раскрывает остальные действия. Клавиши прежние, высота кнопок не меньше 44 CSS-пикселей. Панель скрыта до начала игры.

Подсказка Phaser и её кнопка располагаются над текущей высотой DOM-панели, включая раскрытый список. Подробности лагеря и текстовый статус остаются доступны вспомогательным технологиям; видимые сведения о состоянии находятся в игровом HUD и меню. Изображения, баланс, свет, топор и механики не заменялись.

Следующие отдельные задачи: согласовать спокойные материалы земли и послойные PNG для внешности. Код фермы использован как пример поведения экрана; файлы другой игры в проект не копировались.

## Целевая проверка

```sh
node --test tests/viewport.test.mjs tests/runtime-entry.test.mjs tests/local-coop.test.mjs
npm run build
python tests/viewport_smoke.py
```

Модельные проверки покрывают пропорции/ограничения холста и совместимость существующего кооператива. Браузерный сценарий проверяет старт без симуляции, заполнение окна, отсутствие прокрутки, изменение размеров, две камеры/возврат к одной, ввод после масштабирования, раскрытие действий, меню паузы и поворот мобильного окна. ПК — WebGL, телефон — Canvas из сборки.

Прошли 14 целевых Node-тестов, сборка и оба браузерных сценария. Снимки: [ПК, кооператив](viewport-desktop.png) · [телефон](viewport-mobile.png).
