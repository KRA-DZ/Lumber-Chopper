# Первый шаг: лес и водная структура

Это схема для следующей реализации, не новая геометрия воды в игре. [Посмотреть PNG](forest-water-plan.png) · [SVG](forest-water-plan.svg). Все 25 квадратов и действующие ориентиры показаны в мировых координатах. Берега и новые игровые текстуры требуют отдельного согласования.

## Уже изменено в игре

- В процедурном лесном декоре больше нет повторяющихся `lostSatchel`, `forestTracks` и `clawMarks`: вместо них используются существующие папоротники, цветы и грибы. В болотном декоре убраны повторные затонувшие фонари, остаются корни и грибы.
- Количество деталей ограничено прежним лимитом, правила свободных троп и расстояний между композициями сохраняются.
- Интерактивные записки/следы конкретных локаций не удалены; сюжетные ID и маршруты дневника сохраняются. Добычу из каждой бывшей декоративной сумки не создаём.

## Предлагаемый водный каркас

| Элемент | Трасса / назначение |
| --- | --- |
| Главная река | С севера `0:-2` через западные регионы, существующую гидротехническую область и озеро `-1:0`, затем на юг к `0:2` |
| Ручей у лагеря — первая реализация | От западного озера к берегу около `(1060,1940)` в стартовом квадрате; виден после короткой прогулки из лагеря |
| Северное ответвление | Севернее крепости, через `1:-1` к восточному краю карты; широкое пересечение с северной дорогой |
| Южное ответвление | Через южные регионы, севернее машинного двора лесопилки; подходы к торговцу и погрузке сохраняются |
| Большое озеро | В существующем рыболовном регионе `-1:0`, с расширенными берегами, камышом и несколькими подходами; не создаёт вторую независимую рыбалку поверх нынешней |
| Малые пруды | Кандидаты в `-2:-1`, `1:-2`, `2:2`, `-2:2`; сначала оформление, без обещания интерактивной рыбалки в каждом |

Река на рисунке схематична; толщины не задают будущие хитбоксы. Отметки переходов — кандидаты, а не уже построенные мосты. Перед изменением воды проверить пересечения с дорогами, структурами и локальными точками интереса.

## Как внедрять следующим этапом

1. Сначала только ручей у лагеря → существующее западное озеро. Общая модель берега для изображения, воды и коллизий, без физической симуляции жидкости.
2. Предусмотреть доступный переход и широкий обход. Проверить выход из стартового квадрата, покупателей, доставку тележкой, оператора и оба комплекта управления.
3. Согласовать новую геометрию с плотиной/высоким и низким уровнем воды, бродом и гидростанцией. Отдельно сверить отрисовку узких каналов низкого уровня с их фактическими коллизиями.
4. Только после проверки маршрутов распространять реку по северной/южной схеме. При открытии региона не менять внезапно уже пройденный берег.
5. Затем согласовать набор берегов/растений и добавить ягодные кусты. Они, новые грибы и плавные материалы земли относятся к следующим шагам; новых несогласованных игровых ассетов в этом обновлении нет.

Текущие проверки очистки леса: `tests/lantern-cone.test.mjs` (все регионы), `tests/biome-atmosphere.test.mjs`, `tests/regions.test.mjs`. Этот план сам по себе не требует запуска всей игры или изменения стоимости регионов.
