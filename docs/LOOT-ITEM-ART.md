Все варианты выполнены в общей пиксельной стилистике; это выбор дизайна предметов, а не новый режим графики. Реликвия из сумки — обычная археологическая находка; жетон крепости и бирка лесопилки остаются отдельными сюжетными предметами.

## Подключение №3

1. Из выбранного ряда подготовлен [отдельный чистый лист](../art/source/loot-items-selected-3-sheet.png), без номеров и подписей. `scripts/prepare_loot_items.py` переиспользует существующую нарезку по alpha, сохраняет светлые детали и обнуляет скрытый RGB. Белый цвет не удаляется по цвету.
2. В `src/assets/loot-items/` находятся атлас 128×128, манифест с SHA-256 исходника/основаниями и семь иконок 32×32. Монеты и смола показываются на земле, ключ/смола/мазь/реликвия — в сумке и предложениях торговца, монеты — в лавке. Рыба пока сохраняет прежнее оформление.
3. Удочка и поплавок используют PNG. Удочка зеркалится при офлайн-подготовке для броска влево; точка руки и кончик задаются в манифесте, леска начинается от настоящего кончика изображения. Рыболовные таймеры и награды прежние.
4. Вблизи добыча выводится поверх крон с небольшим бликом. В тёмную ночь значки и подписи видимы только в доступном свете; улучшение фонаря сохраняет свой радиус. При подборе летят не больше двух значков за событие, максимум шесть одновременно, на 0,45 активной секунды. Пауза останавливает перелёт. Ресурсы начисляются моделью сразу, а не по завершении анимации.

Исходники сохранены без редактирования в `art/source/`, оба — 1536×1024 RGBA PNG. Стилистические ориентиры — утверждённые `items-axes-sheet.png` и `camp-tent-states-sheet.png`. Игровые PNG имеют только alpha 0/255; прозрачные пиксели — RGB 0/0/0. Отдельная временная GPU-текстура удаляется после загрузки, при перезапуске повторно используется сохранённый небольшой источник. Общий атлас остаётся в пределах 2048×2048.

Кадры подключает `phaser/loot-item-assets.js`; отображение добычи и перелётов — `phaser/combat-loot-view.js`, сумка/торговля — `phaser/exploration-ui.js`, снасти — `phaser/exploration-view.js`. Модель денег, цены, шансы и лимиты не менялись.

## Проверки и снимки

Пройдены четыре проверки alpha/белых деталей/размеров/повторяемости подготовки и 22 проверки модели/импортов. Два адресных браузерных сценария в WebGL на ПК и мобильном Canvas проверяют PNG, близкие/освещённые маркеры, лимит и паузу эффектов, сумку, настоящую покупку по иконке, рыбалку, реальный подбор/покупку за добычу и перезапуск сцены. После выравнивания строк и отключения стандартной синей подсветки касания повторена только мобильная часть графического сценария.

```sh
python scripts/prepare_loot_items.py
python tests/loot_item_assets_test.py
node --test tests/runtime-entry.test.mjs tests/combat-loot.test.mjs tests/exploration.test.mjs
npm run build
python tests/loot_item_art_smoke.py

```
