Все варианты выполнены в общей пиксельной стилистике; это выбор дизайна предметов, а не новый режим графики. Реликвия из сумки — обычная археологическая находка; жетон крепости и бирка лесопилки остаются отдельными сюжетными предметами.

## Подключение №3

1. Из выбранного ряда подготовлен [отдельный чистый лист](../art/source/loot-items-selected-3-sheet.png), без номеров и подписей. `scripts/prepare_loot_items.py` переиспользует существующую нарезку по alpha, сохраняет светлые детали и обнуляет скрытый RGB. Белый цвет не удаляется по цвету.
2. В `src/assets/loot-items/` находятся атлас 128×128, манифест с SHA-256 исходников/основаниями и восемь иконок 32×32. Монеты и смола показываются на земле, ключ/смола/мазь/реликвия/рыба — в сумке, монеты — в лавке. Новый [окунь](../art/source/loot-perch-style-3.png) заменяет прежний процедурный кадр рыбы при вылове; дополнительный атлас не требуется.
3. Удочка и поплавок используют PNG. Удочка зеркалится при офлайн-подготовке для броска влево; точка руки и кончик задаются в манифесте, леска начинается от настоящего кончика изображения. При поклёвке поплавок притапливается и дрожит, круги становятся золотистыми, активная кнопка подсечки выделяется цветом. Движение использует игровое время и замирает на паузе. Рыболовные таймеры и награды прежние.
4. Вблизи добыча выводится поверх крон с небольшим бликом. В тёмную ночь значки и подписи видимы только в доступном свете; улучшение фонаря сохраняет свой радиус. При подборе летят не больше двух значков за событие, максимум шесть одновременно, на 0,45 активной секунды. Пауза останавливает перелёт. Ресурсы начисляются моделью сразу, а не по завершении анимации.

Исходники сохранены без редактирования в `art/source/`: листы — 1536×1024, окунь — 1774×887 RGBA PNG с настоящей прозрачностью. Стилистические ориентиры — утверждённые `items-axes-sheet.png` и `camp-tent-states-sheet.png`. Игровые PNG имеют только alpha 0/255; прозрачные пиксели — RGB 0/0/0. Отдельная временная GPU-текстура удаляется после загрузки, при перезапуске повторно используется сохранённый небольшой источник. Общий атлас остаётся в пределах 2048×2048.

Кадры подключает `phaser/loot-item-assets.js`; отображение добычи и перелётов — `phaser/combat-loot-view.js`, сумка/торговля — `phaser/exploration-ui.js`, снасти — `phaser/exploration-view.js`. Модель денег, цены, шансы и лимиты не менялись.

## Проверки и снимки

Для добавления рыбы пройдены четыре проверки alpha/светлых деталей/размеров/повторяемости подготовки, тесты модели исследования/импортов и графический сценарий на ПК WebGL и мобильном Canvas из `dist/`. Он проверяет пять иконок сумки, настоящую покупку, активную поклёвку, подсечку кнопкой, получение ровно одной рыбы с PNG и перезапуск. Экономический сценарий добычи сохранён отдельно; для этого изменения он не повторялся.

```sh
python scripts/prepare_loot_items.py
python tests/loot_item_assets_test.py
node --test tests/runtime-entry.test.mjs tests/combat-loot.test.mjs tests/exploration.test.mjs
npm run build
python tests/loot_item_art_smoke.py
python tests/combat_loot_smoke.py
```

Запасы и позиции графических сценариев задаются фикстурами; обычная игра начинается с нуля. Исходники, коллаж и снимки не входят в сборку. Новых библиотек нет; замер FPS на физическом телефоне не выполнялся.

Пакет предметов с манифестом и восемью иконками занимает 24 022 байта. Распакованный источник кадров остаётся 64 KiB RGBA; иконки загружаются интерфейсом по мере использования. Общая сборка и совмещённая нагрузка описаны в [WORLD-READABILITY.md](WORLD-READABILITY.md).
